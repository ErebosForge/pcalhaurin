# AlhaurinPC — Site Specification

## Overview

Single-page static website advertising PC repair services in Alhaurín de la Torre and surrounding areas. Two languages (ES default, EN for expats). Optimized for local SEO and AI search (GEO).

## Target Audience

1. **Primary**: Spanish-speaking locals (30-65 years) in Alhaurín de la Torre area with a broken PC/laptop
2. **Secondary**: English/German-speaking expats in the same area

## Services Offered

- Formateo y reinstalación de Windows
- Eliminación de virus/malware
- Ampliación de RAM/SSD
- Diagnóstico y reparación (no arranca, pantalla azul, lento)
- Configuración de redes WiFi
- Recuperación de datos
- Creación de páginas web sencillas (future)

## Zones Covered

- Alhaurín de la Torre
- Alhaurín el Grande
- Cártama / Estación de Cártama
- Campanillas
- Churriana
- Pizarra

## Content Requirements (per language)

- Hero: headline + CTA (phone/WhatsApp)
- Services: list with brief description + indicative price
- Zones: explicit list of covered areas
- About: 2-3 lines, credibility (years of experience)
- Contact: phone, WhatsApp, hours
- NO contact form (overkill, WhatsApp is faster)

## Technical Requirements

- Mobile-first responsive design
- Lighthouse Performance ≥ 90
- Lighthouse Accessibility ≥ 95
- Lighthouse SEO ≥ 95
- Schema.org LocalBusiness JSON-LD
- Open Graph tags (WhatsApp preview)
- hreflang alternates (ES ↔ EN)
- sitemap.xml + robots.txt (auto-generated by Hugo)
- Page load < 1s (it's static HTML, should be trivial)

## SEO Strategy

### On-page
- Title: "Reparación de Ordenadores en Alhaurín de la Torre | AlhaurinPC"
- H1: Contains primary keyword + location
- Content: factual, specific (prices, times, zones)
- Each zone mentioned explicitly (for long-tail)

### Off-page
- Google Business Profile (primary traffic source for local)
- Bing Webmaster Tools (ChatGPT uses Bing)
- Local directories: Páginas Amarillas, QDQ, Cronoshare
- Reviews: target 5+ reviews in first month

### GEO (AI Search Optimization)
- Schema.org structured data with full service/area detail
- Content written as citable facts (not vague marketing)
- NAP consistency across all platforms
- Review volume as trust signal
